fw-hdl spec
===========

The implementation-independent specification of fw-hdl. This reference
covers layer 1 of the SystemVerilog API, ``fw_hdl_pkg``: components,
signals, ports, bundles and externs; and the domain layer: clocks, resets
and user-defined kinds of domain.
